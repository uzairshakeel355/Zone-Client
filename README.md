# Zone-Client

Frontend for ShopZone — Angular 17, Angular Material, Tailwind CSS, NgRx.

## Prerequisites
- Node.js 18.13+ / 20.9+
- Angular CLI 17

## Setup
1. `npm install`
2. Set your backend URL in `src/environments/environment.development.ts`
3. `ng serve` → open `http://localhost:4200`

## Stack
Angular 17 (standalone) · Angular Material · Tailwind CSS · NgRx · JWT via interceptor + route guard
