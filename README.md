# Zone-Client

Frontend for ShopZone — Angular 17, Angular Material, Tailwind CSS, NgRx.

## Prerequisites
- Node.js 18.13+ / 20.9+
- Angular CLI 17

## Setup
1. `npm install`
2. Set your backend URL in `src/environments/environment.development.ts`
3. `ng serve` → open `http://localhost:4200`

## Stack
Angular 17 (standalone) · Angular Material · Tailwind CSS · NgRx · JWT via interceptor + route guard

## Scope
Weeks 1-4 complete: authentication, product/category catalog, cart, and checkout/orders.
Weeks 5-8 (admin panel, real-time order tracking, search/performance, deployment) were
scoped in the original plan but not built — documented here as a clear extension path,
not an oversight.
